# Archive

This folder keeps historical scripts, logs, validation outputs, and experiments
that are useful for provenance but are not part of the maintained run path.

Current active workflows live under:

- `processing/`
- `models/*/training/`
- `analysis/`

Archived contents include:

- `engine_validation/`: small B3LYP validation structures/results.
- `modal/`: earlier Modal training/evaluation scripts.
- `beamstop_experiments/`: earlier beamstop sweeps and plots.
- `training_logs/`: old Slurm logs from previous runs.
